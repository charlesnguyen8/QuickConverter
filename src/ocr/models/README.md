PP-OCRv6 small detection/recognition models and the full dictionary, from
https://huggingface.co/snowfluke/ppu-paddle-ocr-models (Apache-2.0, derived from PaddleOCR).
Bundled so image-chapter OCR runs offline in the extension and the app. The small tier has the
full character dictionary (about 18,700 entries), so rare characters in novels can be read.
